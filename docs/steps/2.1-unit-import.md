## ต้องได้อะไร

หน้า `src/app/(app)/plots/import/page.tsx` (ตอนนี้เป็นหน้าว่าง ให้เขียนทับ) เปิดจากปุ่ม "นำเข้ารายการแปลง" ในหน้าโครงการ (`/plots/import?project=<id>`) — **แอดมินเท่านั้น** (`requireMe(["admin"])`)

1. เลือกโครงการ (ค่าเริ่มจาก `?project=`) แล้วเลือกไฟล์ `.xlsx` หรือ `.csv`
2. อ่านไฟล์ในเบราว์เซอร์ ไม่อัปโหลดไฟล์ขึ้นเซิร์ฟเวอร์ — `.xlsx` ใช้แพ็กเกจ `read-excel-file` (`npm i read-excel-file@9`) แบบ `import { readSheet } from "read-excel-file/browser"` อ่านชีตแรก · `.csv` อ่านเอง (รองรับ UTF-8 มี BOM)
3. จับหัวคอลัมน์ด้วย `UNIT_IMPORT_COLUMNS` ใน `src/config/units.ts` (ชื่อไทย → key ที่ฐานข้อมูลรับ) ตัดช่องว่างหน้า-หลังก่อนเทียบ ถ้าขาดคอลัมน์ "เลขแปลง" ให้แจ้งชัด ๆ ว่าขาดคอลัมน์ไหน
4. **หน้าตรวจก่อนนำเข้า**: ตารางทุกแถว (มือถือเป็นการ์ด) + สรุปด้านบน: จำนวนแปลง · ราคารวม · ราคาต่ำสุด–สูงสุด · จำนวนแต่ละสถานะ · แถวที่มีปัญหาขึ้นสีเตือนพร้อมเหตุผล:
   - ไม่มีเลขแปลง · เลขแปลงซ้ำกันในไฟล์ · ราคาไม่ใช่ตัวเลข หรือ 0 · สถานะไม่อยู่ใน 5 คำ
   - เลขแปลงที่มีอยู่แล้วในโครงการ (เช็กจากตาราง `units`) ให้ป้าย "อัปเดต" แถวใหม่ป้าย "เพิ่มใหม่" — ฐานข้อมูลเก็บเลขแปลงเป็นตัวพิมพ์ใหญ่ไม่มีช่องว่าง (`upper(trim(code))`) ให้เทียบแบบเดียวกันทั้งตรงนี้และตอนหาเลขซ้ำในไฟล์
   - ฐานข้อมูลไม่ตรวจราคาเป็น 0 ให้ (ตัดตัวที่ไม่ใช่ตัวเลขทิ้งเฉย ๆ) หน้านี้ต้องตรวจเอง
5. ปุ่มนำเข้าใช้ `ConfirmCard` บอก "เพิ่มใหม่ X แปลง · อัปเดต Y แปลง · ราคารวม Z บาท" ปุ่มยืนยันชื่อ "ยืนยันนำเข้า N แปลง" (ปุ่มเป็นสีเทาถ้ายังมีแถวที่ผิด)
6. ส่งทั้งหมดใน RPC `import_units(p_project, p_rows)` ครั้งเดียว (`p_rows` = array ของ `{code, zone, house_type, land_sqw, usable_sqm, price, status, note}` ค่าเป็นข้อความตามไฟล์ได้เลย ฐานข้อมูลแปลงตัวเลขและสถานะภาษาไทยให้)
7. แสดงผลที่ได้กลับมา: เพิ่มใหม่ · อัปเดต · แถวที่ไม่ผ่าน (`errors`) แล้วมีปุ่ม "ดูผังและสถานะแปลง" ไป `/plots?project=<id>`

## ใช้ของที่มีแล้ว (ห้ามสร้างซ้ำ)

`import_units` ใน `supabase/migrations/0004_units.sql` · `UNIT_IMPORT_COLUMNS` และ `UNIT_STATUS` ใน `src/config/units.ts` · `src/components/ui/*` · `baht()` ใน `src/lib/format.ts`

## ห้ามแตะ

`supabase/migrations/` · `src/app/globals.css` · ของเดิมใน `src/components/ui/` · หน้า `/plots` และ `/projects` (ทำไว้แล้ว) — ไฟล์ของขั้นนี้ทั้งหมดอยู่ใน `src/app/(app)/plots/import/` (Server Action ที่ `src/app/(app)/plots/import/actions.ts`)

## ตรวจผลยังไง (ผู้เรียนทำเอง)

1. ล็อกอินเป็นแอดมิน เปิด http://localhost:3000/projects → เข้าโครงการ → กด "นำเข้ารายการแปลง"
2. เลือกไฟล์ → ตรวจว่าราคารวมและจำนวนแปลงตรงกับไฟล์ → ยืนยัน
3. แก้ราคาแปลงหนึ่งในไฟล์ แล้วนำเข้าซ้ำ → ต้องขึ้น "อัปเดต 1" ไม่ใช่เพิ่มแปลงซ้ำ
4. เปิด http://localhost:3000/plots → แปลงที่นำเข้าขึ้นครบ (ถ้ายังไม่มีผัง จะเห็นรายการและช่องค้นหาเลขแปลง) · ลองเปิด 2 เครื่อง เครื่องหนึ่งจองแปลง อีกเครื่องเปลี่ยนสีเองโดยไม่ต้องรีเฟรช
5. `npm run build` ผ่าน แล้ว commit ชื่อ `Step 2.1: unit import`
