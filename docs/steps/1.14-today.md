## ต้องได้อะไร

หน้าแรกของเซลส์ `src/app/(app)/today/page.tsx` (ตอนนี้เป็นหน้าว่าง ให้เขียนทับ) — เปิดแอปมาแล้วรู้ทันทีว่าวันนี้ต้องตามใคร

หน้าแบ่ง 2 แท็บด้วย `Tabs` (`?tab=visit|follow` เปิดมาเจอแท็บแรก):

### แท็บ 1 "ลูกค้ามาชมโครงการ"
- RPC `upcoming_visits(p_owner, p_all, p_project, p_days => 3)` (migration 0019) ได้นัดชม วันนี้ · พรุ่งนี้ · มะรืน พร้อม `arrived_at`
- ดึงประวัติ 5 ครั้งล่าสุด (`activities`) และแปลงที่สนใจ (`unit_interests` + `units(code, house_type)`) ของลูกค้าที่มีนัด แล้ววาง `<UpcomingVisits rows context ownerFor canLog now />` ที่ทำไว้แล้ว (`src/components/lead/upcoming-visits.tsx`: แถบสีแยกวัน · ป้ายมาแล้ว/เลยเวลา/โทรยืนยัน · ปุ่มเช็กอิน)

### แท็บ 2 "ติดตามความคืบหน้า"
- ดึงข้อมูลด้วย RPC `today_list(p_owner, p_all, p_project)` (migration 0014) ครั้งเดียว ผ่าน `fetchAllRpc` (ได้ลีดที่ยังไม่ปิด พร้อม `bucket`) · โครงการมาจาก `scopeProjectId()`
- ด้านบน: `StatusTabs` ทั้งหมด · เลยกำหนด · ต้องตามวันนี้ · ลีดใหม่ พร้อมจำนวน (`?show=`)
- แบ่ง 4 กลุ่ม เรียงตามความเร่งด่วน (หัวกลุ่มมีจำนวน):
  1. `overdue` **เลยกำหนดแล้ว** — แถบ/ป้ายสีแดง พร้อมข้อความ "เลย N วัน" (ไม่ใช้สีอย่างเดียว)
  2. `new` **ลีดใหม่ที่ยังไม่ได้ติดต่อ**
  3. `today` **ต้องตามวันนี้**
  4. `week` **7 วันข้างหน้า** (ยุบไว้ กดเปิดดูได้)
- การ์ดวางเรียง 2 ใบต่อแถวบนจอใหญ่ ใส่ `@container` ที่การ์ด ให้ปุ่มย้ายลงใต้ข้อความเมื่อการ์ดแคบ (กฎข้อ 4)
- แต่ละรายการ: ชื่อ · โครงการ · `StageBadge` · โน้ตล่าสุด (บรรทัดเดียว) · เวลานัดชมถ้ามี · ปุ่ม **โทร** (`tel:`) · ปุ่ม **บันทึกผล** (เปิด `log-activity-sheet` จากขั้น 1.13 บันทึกแล้วรายการหายจากกลุ่มเอง) · กดชื่อไปหน้าลูกค้า
- บันทึกผลจบใน 3 ครั้งกด: บันทึกผล → พิมพ์โน้ต → กดปุ่มลัดวันตาม (ปุ่มลัดบันทึกให้เลย ทำไว้แล้วในขั้น 1.13)
- ไม่มีงานเลย = `EmptyState` "วันนี้ไม่มีงานค้าง" + ปุ่มเพิ่มลีด
- action ของขั้น 1.13 เรียก `afterLeadChange()` อยู่แล้ว เพิ่มแค่ `revalidatePath("/today")` ให้รายการอัปเดตหลังบันทึก

แอดมินและผู้บริหาร: มี `MemberDropdown` "ดูงานของ" (ทั้งทีม · ฉัน · รายคน → `p_all` / `p_owner`) และการ์ดแสดงรูปเซลส์เจ้าของลีด

## ตรวจผลยังไง (ผู้เรียนทำเอง)

1. ล็อกอินเป็นเซลส์ เปิด http://localhost:3000/today
2. แท็บ "ลูกค้ามาชมโครงการ": เปลี่ยนขั้นลูกค้าสักคนเป็นนัดชมวันนี้ → ขึ้นในแถบ "วันนี้" พร้อมเวลา · กดเช็กอิน → ขึ้น "มาแล้ว"
3. แท็บ "ติดตามความคืบหน้า": ลีดที่เพิ่งเพิ่มในขั้น 1.13 ต้องอยู่กลุ่ม "ลีดใหม่"
4. กด **บันทึกผล** → ใส่โน้ต → กด "พรุ่งนี้" → รายการย้ายไปกลุ่ม "7 วันข้างหน้า"
5. ให้เพื่อนเพิ่มลีดอีกราย → รีเฟรช → ขึ้นในกลุ่มลีดใหม่
6. ดูบนมือถือ 375px → ปุ่มโทรและบันทึกผลกดง่าย ไม่ล้นจอ
7. `npm run build` ผ่าน แล้ว commit ชื่อ `Step 1.14: today page`
