# ข้อมูลตัวอย่างสำหรับสาธิต (อาจารย์ใช้ · ผู้เรียนไม่ต้องรัน)

ได้ 2 โครงการพร้อมรูปปก ("เดอะ กรีนวิลล์ บางนา" 47 แปลงพร้อมผังและหมุด · "ทาวน์ พาร์ค รามอินทรา" 40 แปลง) ทีมขายสมมติ 4 คน + ผู้บริหาร 1 คน (อีเมล @example.com ล็อกอินไม่ได้) ลูกค้า 62 รายย้อนหลัง 45 วัน มีบันทึกการโทร แชต พาชมพร้อมรูป การจอง และผลคัดกรองสินเชื่อ

## ใส่ข้อมูล (หลังรันฐานข้อมูลครบทุกไฟล์แล้ว)

    python3 scripts/make-demo-seed.py          # สร้าง supabase/demo/seed_demo.sql (วันที่นับจากวันนี้)
    supabase db query --linked -f supabase/demo/seed_demo.sql
    node scripts/upload-demo-media.mjs         # รูปปก ผัง และรูปเช็กอิน (ใช้ค่าใน .env.local)

หรือวาง `seed_demo.sql` ใน SQL Editor แล้วค่อยรันคำสั่งอัปโหลดรูป

รันซ้ำได้ทุกเมื่อ สคริปต์ลบข้อมูลสาธิตชุดเดิมก่อน (เฉพาะ 2 โครงการนี้และพนักงานสมมติ ข้อมูลอื่นไม่ถูกแตะ) — รันใหม่ก่อนสอนเพื่อให้วันที่เป็นปัจจุบัน
