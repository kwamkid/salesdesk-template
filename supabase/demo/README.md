# ข้อมูลตัวอย่าง (ใส่เองได้ · ล้างออกได้)

บอก Claude ภาษาธรรมดาได้เลย: **"ใส่ข้อมูลตัวอย่างให้หน่อย"** หรือ **"ล้างข้อมูลตัวอย่างออก"**

ได้ 2 โครงการพร้อมรูปปก ("เดอะ กรีนวิลล์ บางนา" 47 แปลงพร้อมผังและหมุด · "ทาวน์ พาร์ค รามอินทรา" 40 แปลง) ทีมขายสมมติ 4 คน + ผู้บริหาร 1 คน (อีเมล @example.com ล็อกอินไม่ได้) ลูกค้า 62 รายย้อนหลัง 45 วัน มีบันทึกการโทร แชต นัดชม พาชมพร้อมรูป การจอง และผลคัดกรองสินเชื่อ

## ใส่ข้อมูล (หลังรันฐานข้อมูลครบทุกไฟล์แล้ว)

    python3 scripts/make-demo-seed.py          # สร้าง seed_demo.sql + clear_demo.sql (วันที่นับจากวันนี้)
    supabase db query --linked -f supabase/demo/seed_demo.sql
    node scripts/upload-demo-media.mjs         # รูปปก ผัง และรูปเช็กอิน (ใช้ค่าใน .env.local)

ไม่ได้ต่อ Supabase CLI: เปิด `seed_demo.sql` คัดลอกทั้งไฟล์ไปวางใน SQL Editor แล้วกด Run จากนั้นค่อยรันคำสั่งอัปโหลดรูป

รันซ้ำได้ทุกเมื่อ สคริปต์ลบข้อมูลตัวอย่างชุดเดิมก่อน — รันใหม่ก่อนสอนเพื่อให้วันที่เป็นปัจจุบัน (เช่น นัดชมวันนี้/พรุ่งนี้)

## ล้างข้อมูลตัวอย่าง

    supabase db query --linked -f supabase/demo/clear_demo.sql

(หรือวาง `clear_demo.sql` ใน SQL Editor) ลบเฉพาะ 2 โครงการตัวอย่าง ลูกค้าและแปลงของมัน พนักงานสมมติ และแคมเปญตัวอย่าง — โครงการ ลูกค้า และพนักงานจริงของคุณไม่ถูกแตะ
